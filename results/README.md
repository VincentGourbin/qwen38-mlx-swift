# Measurement evidence

Raw output kept only where `docs/knowledge/log.md` or `PLAN.md` cites it as
evidence for a specific claim. Everything else was pruned: the conclusions
live in the log, not in the raw files.

Profiler traces (`*.trace.json`, `*.trace/`) are regenerable and gitignored —
see `docs/knowledge/log.md` for the commands that produced them.
