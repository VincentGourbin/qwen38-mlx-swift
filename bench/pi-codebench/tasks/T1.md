## T1 — Lire la consommation de jetons d'une réponse

Le serveur renvoie, dans chaque réponse `/v1/chat/completions`, un bloc `usage` :

```json
"usage": {"prompt_tokens": 1200, "completion_tokens": 150, "total_tokens": 1350,
          "prompt_tokens_details": {"cached_tokens": 800}}
```

À faire, dans `Sources/AgentKit/AgentWireFormat.swift` :

1. Une nouvelle structure publique `AgentTokenUsage` (`Equatable`, `Sendable`) avec trois
   propriétés `Int` : `promptTokens`, `completionTokens`, `cachedTokens`, et un
   initialiseur public `init(promptTokens:completionTokens:cachedTokens:)` où
   `cachedTokens` vaut `0` par défaut.
2. Une propriété publique `usage: AgentTokenUsage?` sur `AgentModelTurn`, ajoutée comme
   dernier paramètre de son initialiseur, `nil` par défaut (les appels existants
   doivent continuer de compiler).
3. `AgentWireFormat.parseChatCompletionResponse` remplit `usage` :
   - bloc `usage` absent → `nil` ;
   - `prompt_tokens` ou `completion_tokens` manquant → `0` pour ce champ ;
   - `prompt_tokens_details` ou `cached_tokens` absent → `cachedTokens = 0`.

Critère : `swift build` et `swift test` passent ; ajoute au moins un test pour ce
comportement dans `Tests/AgentKitTests/`.
